# Auto-Ticket-Classification-Using-Flow-Designer-Project
Automated ticket classification and routing system built with ServiceNow Flow Designer. Automatically evaluates ticket details, assigns category and priority, routes tickets to the appropriate support group, and handles unmatched tickets through a manual triage queue.

# Auto Ticket Classification using Flow Designer

An automated ticket classification and routing solution built using
ServiceNow Flow Designer.

## 🚀 Overview

The system automates the initial triage of Incident and Service Request
tickets by evaluating ticket information and applying configured
classification and routing rules.

## ✨ Key Features

- Automatic ticket triggering
- Ticket content evaluation
- Automatic category classification
- Priority assignment
- Assignment group routing
- Unmatched ticket fallback handling
- General Support Triage Queue
- Workflow and audit tracking

## 🏗️ Workflow

Ticket Creation
↓
Flow Designer Trigger
↓
Content Evaluation & Parsing
↓
Decision Matrix & Conditional Branching
↓
Category + Priority + Assignment Group
↓
Support Team
↓
Ticket Resolution

Unmatched Ticket
↓
General Support Triage Queue
↓
Manual Review
